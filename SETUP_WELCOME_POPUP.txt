WELCOME POPUP - setup (3 steps)

1. Copy the files from this zip into your project, keeping the same folders
   (it overwrites prisma/schema.prisma, app/layout.tsx and
   app/admin/(protected)/layout.tsx, and adds the new files).

2. Create the new table (this only ADDS one table, nothing existing changes):
       npx prisma db push
       npx prisma generate
   If db push warns about data loss on any OTHER table, answer "no" and stop.
   Then delete the .next folder and restart:  npm run dev

3. Admin -> Welcome Popup: add image / title / text / checklist / Telegram link,
   tick "Show the popup to visitors", Save.
   To test as a first-time visitor: open the site in an Incognito window
   (or clear the site's localStorage key "sharustore_welcome_seen").

Run step 2 BEFORE pushing to Vercel. (If you forget, the site still works -
the popup just stays hidden and the admin page tells you to run db push.)
Tick "Show again to everyone" when saving a NEW promotion so people who
already closed the old popup see it once more.
